# 🏁 Automated CNC Benchmark Harness (Agent vs. FreeCAD CAM Workbench)

This directory contains the autonomous, headless benchmark system comparing machine code generated by the **Autonomous CNC Agent** against the **FreeCAD CAM Workbench**.

---

## 🚀 Quickstart

Run a head-to-head comparison on any part:

```bash
# Benchmark Part 10 (Flange Housing)
python3 benchmark_runner.py --part 10

# Benchmark Part 02 (Single Pocket)
python3 benchmark_runner.py --part 02

# Benchmark Part 06 (The Machinability Refusal Proof)
python3 benchmark_runner.py --part 06

# Benchmark ANY arbitrary new STEP file
python3 benchmark_runner.py --cad /path/to/any_part.step

# Run all benchmark parts
python3 benchmark_runner.py --all
```

---

## 📊 Viewing the Benchmark Reports

1. **Interactive HTML Dashboard:**
   ```bash
   xdg-open reports/benchmark_report.html
   ```
2. **Markdown Summary Table:**
   ```bash
   cat reports/benchmark_summary.md
   ```
3. **Machine-Readable Raw JSON:**
   `reports/benchmark_results.json`

## 📁 Directory Layout

- `benchmark_runner.py`: Master CLI runner for single or batch benchmarks.
- `generate_freecad_baseline.py`: Headless FreeCAD CAM toolpath generator.
- `_freecad_worker.py`: FreeCAD Python worker running under `freecadcmd`.
- `run_agent_wrapper.py`: Execution wrapper for the autonomous agent.
- `compare_gcode.py`: Kinematic comparator for cycle times, air-cut ratios, and retracts.
- `baselines/`: Pre-computed FreeCAD CAM golden reference G-code (`.ngc`).
- `runs/`: Agent run artifacts (multi-tool G-code, CAMotics simulation files).
- `reports/`: Generated benchmark scorecards and HTML dashboard.
